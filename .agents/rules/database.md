# Database — Drizzle + PostgreSQL

Reference: `src/modules/users/infrastructure/persistence/`.

## Schemas

- File: `infrastructure/persistence/<x>.schema.ts`, exported `pgTable`.
- Table: plural `snake_case` (`order_items`). Columns: camelCase in TS with an
  explicit snake_case name (`passwordHash: varchar('password_hash', …)`).
- `id: uuid('id').primaryKey()` — generated by the app (`randomUUID()` in the
  use-case), no DB default.
- `createdAt` / `updatedAt`: `timestamp(…, { withTimezone: true }).notNull().defaultNow()`.
- Strings: `varchar` with an explicit `length`. Add `.unique()` / indexes the
  feature actually needs.
- Foreign keys: declare them with `.references(() => parent.id, { onDelete })`
  and choose `onDelete` explicitly.
- Export the row types right below the table:

  ```ts
  export type OrderRow = typeof orders.$inferSelect;
  export type NewOrderRow = typeof orders.$inferInsert;
  ```

- Re-export the file from `src/shared/database/schema.ts` — the single barrel
  read by `drizzle.config.ts` and by the typed `Database`.

## Mapper and repository

- `<x>.mapper.ts`: an object `XMapper = { toDomain(row), toPersistence(entity) }`.
  `toDomain` rebuilds through `X.create(...)` so invariants are checked.
- `drizzle-<x>.repository.ts`: `@Injectable()` class implementing the port,
  `constructor(@Inject(DATABASE_CONNECTION) private readonly db: Database)`.
- Rows never leave the adapter: return entities (or port record types).
- Single-row reads: `.limit(1)` + destructure `[row]`, return `null` when
  missing. Writes use `.returning()` and map the row back.
- Translate unique violations (`23505`) into the module's domain exception
  (`errors.md`).

## Migrations

| Situation                      | Command                                         |
| ------------------------------ | ----------------------------------------------- |
| Prototyping locally            | `pnpm db:push` (no files)                       |
| Change that will be shipped    | `pnpm db:generate` → review SQL → `pnpm db:migrate` |
| Deploy / CI                    | `pnpm db:migrate:run` (programmatic migrator)   |

- `drizzle/` is generated output: never hand-edit migrations or snapshots.
- Generate locally, not in CI — drizzle-kit asks interactively about renames.
- Read the generated SQL before reporting done; destructive statements
  (`DROP`, type changes) must be called out to the developer.
